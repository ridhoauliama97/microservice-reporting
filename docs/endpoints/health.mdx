`GET /health`

Endpoint liveness. **Tidak** memerlukan autentikasi dan **tidak** menyentuh database, Redis, maupun Gotenberg — jawaban selalu instan.

<ResponseField name="status" type="string" required>
Selalu bernilai `"ok"` selama prosesnya masih hidup.
</ResponseField>

## Request

Tidak ada Headers, Path Parameters, Query Parameters, maupun Request Body.

<CodeGroup>

```bash Request
curl.exe http://localhost:5006/health
```

```javascript JavaScript
const res = await fetch('http://localhost:5006/health')
console.log(await res.json())
```

</CodeGroup>

## Response

<CodeGroup>

```json 200 Success
{
  "status": "ok"
}
```

```json Error
{
  "error": {
    "code": "INTERNAL_ERROR",
    "message": "Terjadi kesalahan internal pada server"
  }
}
```

</CodeGroup>

<Note>
Untuk memeriksa kesiapan komponen yang benar-benar dipakai worker — database, Redis, dan Gotenberg — pakai [`/health/ready`](/endpoints/health-ready), bukan endpoint ini.
</Note>
