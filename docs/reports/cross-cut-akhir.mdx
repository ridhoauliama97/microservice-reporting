| `dashboard-cross-cut-akhir` | Laporan Dashboard Cross Cut Akhir | `tglAwal`, `tglAkhir` | `SPWps_LapDashboardCCAkhir` | — |

| `mutasi-cross-cut-akhir` | Laporan Mutasi Cross Cut Akhir (m3) | `tglAwal`, `tglAkhir` | `SP_Mutasi_CCAkhir`, `SP_SubMutasi_CCAkhir` | landscape |
| `rekap-produksi-cross-cut-akhir-consolidated` | Laporan Rekap Produksi CCAkhir Consolidated | `tglAwal`, `tglAkhir` | `SP_LapRekapProduksiCrossCutAkhirConsolidated` | landscape |
| `rekap-produksi-cross-cut-akhir-per-jenis-per-grade` | Laporan Rekap Produksi CCAkhir Per-Jenis & Per-Grade (m3) | `tglAwal`, `tglAkhir` | `SP_LapRekapProduksiCCAkhirPerJenisPerGrade` | portrait |
| `umur-cross-cut-akhir-detail` | Laporan Umur CCAkhir Detail | `umur1`?, `umur2`?, `umur3`?, `umur4`? | `SP_LapUmurCrossCutAkhir` | — |

## Sumber data

### `cross-cut-akhir-hidup-detail`

- Stored procedure: `SP_LapCCAkhirHidupDetail`
- Nama parameter SP: procedure tidak punya parameter
- Orientasi: —

### `dashboard-cross-cut-akhir`

- Stored procedure: `SPWps_LapDashboardCCAkhir`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `ketahanan-barang-cc-akhir`

- Stored procedure: `SP_LapKetahananBarangCCAkhir`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `mutasi-cross-cut-akhir`

- Stored procedure: `SP_Mutasi_CCAkhir`, `SP_SubMutasi_CCAkhir`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `rekap-produksi-cross-cut-akhir-consolidated`

- Stored procedure: `SP_LapRekapProduksiCrossCutAkhirConsolidated`
- Nama parameter SP: `StartDate`, `EndDate` (berbeda dari nama field di `params`)
- Orientasi: landscape

### `rekap-produksi-cross-cut-akhir-per-jenis-per-grade`

- Stored procedure: `SP_LapRekapProduksiCCAkhirPerJenisPerGrade`
- Nama parameter SP: `StartDate`, `EndDate` (berbeda dari nama field di `params`)
- Orientasi: portrait

### `umur-cross-cut-akhir-detail`

- Stored procedure: `SP_LapUmurCrossCutAkhir`
- Nama parameter SP: memakai nama default `@Umur1` dan `@Umur2` dan `@Umur3` dan `@Umur4`
- Orientasi: —

<Warning>
Laporan di bawah ini mengikat nama parameter SP yang **berbeda** dari nama field di `params`. KalauSP-nya diganti nama, nama parameter pun harus ikut menyesuaikan.
</Warning>

| type | Nama field di params | Nama parameter SP |
| --- | --- | --- |
| `rekap-produksi-cross-cut-akhir-consolidated` | `tglAwal`, `tglAkhir` | `StartDate`, `EndDate` |
| `rekap-produksi-cross-cut-akhir-per-jenis-per-grade` | `tglAwal`, `tglAkhir` | `StartDate`, `EndDate` |

## Contoh Request Body

### Bentuk `NoParams` — tanpa params

```json
{
  "type": "cross-cut-akhir-hidup-detail"
}
```

### Bentuk `PeriodParams`

```json
{
  "type": "dashboard-cross-cut-akhir",
  "params": {
    "tglAwal": "2026-09-01",
    "tglAkhir": "2026-09-30"
  }
}
```

### Bentuk `ParamsUmurLaminatingDetail`

```json
{
  "type": "umur-cross-cut-akhir-detail",
  "params": {
    "umur1": 15,
    "umur2": 30,
    "umur3": 60,
    "umur4": 90
  }
}
```
