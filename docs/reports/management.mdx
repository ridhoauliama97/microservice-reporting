## Sumber data

### `dashboard-ru`

- Stored procedure: `SP_LapProduktivitasDashboard`
- Nama parameter SP: `Periode` (berbeda dari nama field di `params`)
- Orientasi: landscape

### `discrepancy-rekap-mutasi`

- Stored procedure: `SP_LapRekapMutasiV2`
- Nama parameter SP: `TglAwal`, `TglAkhir`, `UsingMode` (berbeda dari nama field di `params`)
- Orientasi: landscape

### `flow-produksi-per-periode`

- Stored procedure: `SPWps_LapFlowProduksiPerPeriode`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `hasil-produksi-mesin-lembur-dan-non-lembur`

- Stored procedure: `SPWps_LapLemburPerMesin`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: portrait

### `label-perhari`

- Stored procedure: `SPWps_LapLabelPerhari`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: portrait

### `produksi-hulu-hilir`

- Stored procedure: `SPWps_LapProduksiSemuaMesinV2`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `produksi-semua-mesin`

- Stored procedure: `SPWps_LapProduksiSemuaMesin`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `rekap-mutasi`

- Stored procedure: `SP_Mutasi_BarangJadi`, `SP_Mutasi_CCAkhir`, `SP_Mutasi_FingerJoint`, `SP_Mutasi_KayuBulat`, `SP_Mutasi_KayuBulatKG`, `SP_Mutasi_Laminating`, `SP_Mutasi_Moulding`, `SP_Mutasi_S4S`, `SP_Mutasi_ST`, `SP_Mutasi_Sanding`, `SP_SubMutasi_BarangJadi`, `SP_SubMutasi_CCAkhir`, `SP_SubMutasi_FingerJoint`, `SP_SubMutasi_Laminating`, `SP_SubMutasi_Moulding`, `SP_SubMutasi_S4S`, `SP_SubMutasi_Sanding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: portrait

### `rekap-mutasi-cross-tab`

- Stored procedure: `SP_LapRekapMutasi`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `rekap-stock-on-hand`

- Stored procedure: `SPWps_LapRekapStockOnHand_SubBJ`, `SPWps_LapRekapStockOnHand_SubCCAkhir`, `SPWps_LapRekapStockOnHand_SubFJ`, `SPWps_LapRekapStockOnHand_SubKB`, `SPWps_LapRekapStockOnHand_SubLMT`, `SPWps_LapRekapStockOnHand_SubMoulding`, `SPWps_LapRekapStockOnHand_SubReproses`, `SPWps_LapRekapStockOnHand_SubS4S`, `SPWps_LapRekapStockOnHand_SubST`, `SPWps_LapRekapStockOnHand_SubSanding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: portrait

### `stock-hidup-per-nospk`

- Stored procedure: `SP_LapSemuaStockHidupPerSPK`
- Nama parameter SP: `TglAkhir`, `UsingMode` (berbeda dari nama field di `params`)
- Orientasi: portrait

### `stock-hidup-per-nospk-discrepancy`

- Stored procedure: `SP_LapSemuaStockHidupPerSPK`
- Nama parameter SP: `TglAkhir`, `UsingMode` (berbeda dari nama field di `params`)
- Orientasi: portrait

<Warning>
Laporan di bawah ini mengikat nama parameter SP yang **berbeda** dari nama field di `params`. KalauSP-nya diganti nama, nama parameter pun harus ikut menyesuaikan.
</Warning>

| `discrepancy-rekap-mutasi` | `tglAwal`, `tglAkhir` | `TglAwal`, `TglAkhir`, `UsingMode` |
| `stock-hidup-per-nospk` | `tglAkhir` | `TglAkhir`, `UsingMode` |
