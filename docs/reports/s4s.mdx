## Sumber data

### `dashboard-s4s`

- Stored procedure: `SPWps_LapDashboardS4S`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `dashboard-s4s-v2`

- Stored procedure: `SPWps_LapDashboardS4S2`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `grade-abc-harian`

- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: portrait

### `ketahanan-barang-s4s`

- Stored procedure: `SP_LapKetahananBarangS4S`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `label-s4s-hidup-per-jenis-kayu`

- Stored procedure: `SP_LapRekapProduksiS4SPerJenisPerGrade`

- Orientasi: portrait

### `rekap-produksi-s4s-rambung-per-grade`

- Orientasi: landscape

### `s4s-hidup-detail`

- Stored procedure: `SP_LapS4SHidupDetail`
- Nama parameter SP: procedure tidak punya parameter
- Orientasi: —

### `umur-s4s-detail`

- Stored procedure: `SP_LapUmurS4S`
- Nama parameter SP: memakai nama default `@Umur1` dan `@Umur2` dan `@Umur3` dan `@Umur4`
- Orientasi: —

<Warning>
Laporan di bawah ini mengikat nama parameter SP yang **berbeda** dari nama field di `params`. KalauSP-nya diganti nama, nama parameter pun harus ikut menyesuaikan.
</Warning>

| type | Nama field di params | Nama parameter SP |
| --- | --- | --- |
| `rekap-produksi-s4s-consolidated` | `tglAwal`, `tglAkhir` | `StartDate`, `EndDate` |
| `rekap-produksi-s4s-per-jenis-per-grade` | `tglAwal`, `tglAkhir` | `StartDate`, `EndDate` |
| `rekap-produksi-s4s-rambung-per-grade` | `tglAwal`, `tglAkhir` | `StartDate`, `EndDate` |

## Contoh Request Body

### Bentuk `PeriodParams`

```json
{
  "type": "dashboard-s4s",
  "params": {
    "tglAwal": "2026-09-01",
    "tglAkhir": "2026-09-30"
  }
}
```

### Bentuk `ParamsLabelS4sHidupPerJenisKayu` — tanpa params

```json
{
  "type": "label-s4s-hidup-per-jenis-kayu"
}
```

### Bentuk `NoParams` — tanpa params

```json
{
  "type": "s4s-hidup-detail"
}
```

### Bentuk `ParamsUmurLaminatingDetail`

```json
{
  "type": "umur-s4s-detail",
  "params": {
    "umur1": 15,
    "umur2": 30,
    "umur3": 60,
    "umur4": 90
  }
}
```
