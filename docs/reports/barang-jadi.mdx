## Sumber data

### `barang-jadi-hidup-detail`

- Stored procedure: `SP_LapBJHidupDetail`
- Nama parameter SP: procedure tidak punya parameter
- Orientasi: portrait

### `dashboard-barang-jadi`

- Stored procedure: `SPWps_LapDashboardBJ`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: portrait

### `mutasi-barang-jadi`

- Stored procedure: `SP_Mutasi_BarangJadi`, `SP_SubMutasi_BarangJadi`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `mutasi-barang-jadi-per-jenis-per-ukuran`

- Stored procedure: `SP_LapMutasiBJPerJenisPerUkuran`
- Nama parameter SP: `StartDate`, `EndDate` (berbeda dari nama field di `params`)
- Orientasi: landscape

### `rekap-produksi-barang-jadi-consolidated`

- Stored procedure: `SP_LapRekapProduksiBarangJadiConsolidated`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `rekap-produksi-packing-per-jenis-per-grade`

- Stored procedure: `SP_LapRekapProduksiBarangJadiPerJenisPerGrade`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: portrait

### `saldo-barang-jadi-hidup-per-jenis-per-produk`

- Stored procedure: `SP_LapBJHidupPerProduk`
- Nama parameter SP: procedure tidak punya parameter
- Orientasi: portrait

### `umur-barang-jadi-detail`

- Stored procedure: `SP_LapUmurBarangJadi`
- Nama parameter SP: memakai nama default `@Umur1` dan `@Umur2` dan `@Umur3` dan `@Umur4`
- Orientasi: portrait

<Warning>
Laporan di bawah ini mengikat nama parameter SP yang **berbeda** dari nama field di `params`. KalauSP-nya diganti nama, nama parameter pun harus ikut menyesuaikan.
</Warning>

| type | Nama field di params | Nama parameter SP |
| --- | --- | --- |
| `mutasi-barang-jadi-per-jenis-per-ukuran` | `tglAwal`, `tglAkhir` | `StartDate`, `EndDate` |

## Contoh Request Body

### Bentuk `NoParams` — tanpa params

```json
{
  "type": "barang-jadi-hidup-detail"
}
```

### Bentuk `PeriodParams`

```json
{
  "type": "dashboard-barang-jadi",
  "params": {
    "tglAwal": "2026-09-01",
    "tglAkhir": "2026-09-30"
  }
}
```

### Bentuk `ParamsUmurLaminatingDetail`

```json
{
  "type": "umur-barang-jadi-detail",
  "params": {
    "umur1": 15,
    "umur2": 30,
    "umur3": 60,
    "umur4": 90
  }
}
```
