## Sumber data

### `dashboard-sanding`

- Stored procedure: `SPWps_LapDashboardSanding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `ketahanan-barang-sanding`

- Stored procedure: `SP_LapKetahananBarangSanding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `mutasi-sanding`

- Stored procedure: `SP_Mutasi_Sanding`, `SP_SubMutasi_Sanding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `rekap-produksi-sanding-consolidated`

- Stored procedure: `SP_LapRekapProduksiSandingConsolidated`
- Nama parameter SP: `EndDate`, `StartDate` (berbeda dari nama field di `params`)
- Orientasi: portrait

### `rekap-produksi-sanding-per-jenis-per-grade`

- Stored procedure: `SP_LapRekapProduksiSandingPerJenisPerGrade`
- Nama parameter SP: `EndDate`, `StartDate` (berbeda dari nama field di `params`)
- Orientasi: portrait

### `sanding-hidup-detail`

- Stored procedure: `SP_LapSandingHidupDetail`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `umur-sanding-detail`

- Stored procedure: `SP_LapUmurSanding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

<Warning>
Laporan di bawah ini mengikat nama parameter SP yang **berbeda** dari nama field di `params`. KalauSP-nya diganti nama, nama parameter pun harus ikut menyesuaikan.
</Warning>

| type | Nama field di params | Nama parameter SP |
| --- | --- | --- |
| `rekap-produksi-sanding-consolidated` | `tglAwal`, `tglAkhir` | `EndDate`, `StartDate` |
| `rekap-produksi-sanding-per-jenis-per-grade` | `tglAwal`, `tglAkhir` | `EndDate`, `StartDate` |

## Contoh Request Body

### Bentuk `PeriodParams`

```json
{
  "type": "dashboard-sanding",
  "params": {
    "tglAwal": "2026-09-01",
    "tglAkhir": "2026-09-30"
  }
}
```

### Bentuk `NoParams` — tanpa params

```json
{
  "type": "sanding-hidup-detail"
}
```

### Bentuk `ParamsUmurLaminatingDetail`

```json
{
  "type": "umur-sanding-detail",
  "params": {
    "umur1": 15,
    "umur2": 30,
    "umur3": 60,
    "umur4": 90
  }
}
```
