## Sumber data

### `dashboard-moulding`

- Stored procedure: `SPWps_LapDashboardMoulding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `ketahanan-barang-moulding`

- Stored procedure: `SP_LapKetahananBarangMoulding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `moulding-hidup-detail`

- Stored procedure: `SP_LapMouldingHidupDetail`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: —

### `mutasi-moulding`

- Stored procedure: `SP_Mutasi_Moulding`, `SP_SubMutasi_Moulding`
- Nama parameter SP: memakai nama default `@TglAwal` dan `@TglAkhir`
- Orientasi: landscape

### `rekap-produksi-moulding-consolidated`

- Stored procedure: `SP_LapRekapProduksiMouldingConsolidated`
- Nama parameter SP: `StartDate`, `EndDate` (berbeda dari nama field di `params`)
- Orientasi: landscape

### `rekap-produksi-moulding-per-jenis-per-grade`

- Stored procedure: `SP_LapRekapProduksiMouldingPerJenisPerGrade`
- Nama parameter SP: `StartDate`, `EndDate` (berbeda dari nama field di `params`)
- Orientasi: portrait

### `umur-moulding-detail`

- Stored procedure: `SP_LapUmurMoulding`
- Nama parameter SP: memakai nama default `@Umur1` dan `@Umur2` dan `@Umur3` dan `@Umur4`
- Orientasi: —

<Warning>
Laporan di bawah ini mengikat nama parameter SP yang **berbeda** dari nama field di `params`. KalauSP-nya diganti nama, nama parameter pun harus ikut menyesuaikan.
</Warning>

| type | Nama field di params | Nama parameter SP |
| --- | --- | --- |
| `rekap-produksi-moulding-consolidated` | `tglAwal`, `tglAkhir` | `StartDate`, `EndDate` |
| `rekap-produksi-moulding-per-jenis-per-grade` | `tglAwal`, `tglAkhir` | `StartDate`, `EndDate` |

## Contoh Request Body

### Bentuk `PeriodParams`

```json
{
  "type": "dashboard-moulding",
  "params": {
    "tglAwal": "2026-09-01",
    "tglAkhir": "2026-09-30"
  }
}
```

```json
{
  "type": "umur-moulding-detail",
  "params": {
    "umur1": 15,
    "umur2": 30,
    "umur3": 60,
    "umur4": 90
  }
}
```
